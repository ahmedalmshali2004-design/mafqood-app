# مفقود — المشألي تك

تطبيق ويب عربي متجاوب وقابل للتثبيت (PWA) للمفقودات والموجودات في اليمن. افتح `index.html` أو انشر محتويات هذا المجلد كما هي على استضافة HTTPS.

## الشاشات والوظائف

- ترحيب، دخول تجريبي، متابعة كزائر، حساب وبيانات المطور.
- الرئيسية، البحث بالكلمات، وتصفية المفقودات والموجودات.
- إنشاء بلاغ مع النوع والتصنيف والوصف والمحافظة والمنطقة والتاريخ والصورة ورقم تواصل اختياري.
- صفحة تفاصيل البلاغ، الحفظ للمفضلة، مشاركة الرابط، والتواصل عبر واتساب عند إضافة رقم.
- بلاغاتي، المحفوظات، الرسائل، الدعم الإرشادي، وإدارة البلاغات المخزنة محلياً.
- قائمة المحافظات اليمنية الـ22، تصميم RTL، أيقونات تثبيت Android وiPhone، وتخزين مؤقت لتشغيل الصفحات بعد فتحها.
- يحتفظ النموذج بالبلاغات والحساب والمفضلة على الجهاز باستخدام تخزين المتصفح.

## تجربة التطبيق محلياً

- افتح `index.html` مباشرة لمعاينة الشاشات.
- لاختبار تثبيت PWA، شغّل خادماً محلياً من هذا المجلد (مثلاً `python -m http.server 8080`) ثم افتح `http://localhost:8080`.
- عند النشر على GitHub Pages، ضع `index.html` وملفات المشروع مباشرة في جذر المستودع، ثم اختر `main` و`/(root)` من Settings → Pages.

## حدود النسخة الحالية قبل الإطلاق العام

هذه نسخة Front-end تجريبية قابلة للتثبيت من المتصفح. الحساب تجريبي ومحلي، ولا تُرسل البلاغات إلى مستخدمين آخرين أو خادم. ردود الدعم إرشادية محددة وليست اتصالاً بنموذج ذكاء اصطناعي. أرقام التواصل والصور تبقى في مساحة المتصفح. النشر في Google Play أو App Store يتطلب تغليف PWA كتطبيق أصلي، إعداد خادم وقاعدة بيانات ومصادقة آمنة ورفع صور وربط ذكاء اصطناعي من الخادم، ثم إضافة سياسة الخصوصية وشروط الاستخدام واختبار متطلبات المتاجر.
